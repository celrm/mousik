__________________
Overview

This is a package for writing music in LaTeX. It is based on the tikz package and includes staves, clefs, key and time signatures, notes and chords, rests, beams and tuplets, accidentals, articulations, slurs and ties, dynamics and hairpins, and piano notation. It uses short commands and allows the user to control the position and shape of the musical elements. Everything is written directly in LaTeX without other languages or steps.
