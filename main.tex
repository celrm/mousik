	\begin{abstract}
		This is a music-related package focused on writing music fragments. It works specially well with small examples, such as excerpts for theoretical articles. It is easier than other music writing methods in \LaTeX{} because it is based on the \textsf{tikz} package.

	\section{Introduction}\label{intro}
	There are already several ways to set music using \LaTeX: \textsf{musixtex}, \textsf{lilypond} or \textsf{abc}, among others.
	Some of them are too difficult to use for not too complicated music; others do not work at all.
	
	Based on the \textsf{tikz} package, the \textsf{mousik} package is perfect for short, one line music fragments. It may be used for longer scores, but there are more adaptable and lighter packages than this one. However, in spite of its compactness, the package is quite complete and versatile, but easy to learn and use.
	
	\section{The \texttt{mousik} environment}
	The way to draw a score is by means of the \texttt{mousik} environment. For longer examples, open the \href{run:examples.pdf}{\textit{examples}} document.
	
	\begin{center}
		\begin{mousik}[piano, piano-sep=2]
			\UpperStaff
			\Clef[octave=8] \TimeSig{4}{4}
			\MDots{*/1, , */3, } \Note{|-,=|,|-,=|}{1,2,3,4}
			\Note{4}{2}
			\Artic{^}{0} \Note{8}{0,1}
			\Tie[e=2]{1}
			\Barline
			\Note{1}{1}
			\Barline[t=|.]

			\LowerStaff			
			\Clef[t=4] \TimeSig{4}{4}
			\Note{2}{13/10/8} \Space[1.5]
			\MDot{13}\MDot{9}\MDot{7} \Note{4}{13/9/7} \Space[0.5]
			\Note{8}{12/10/<9/7}
			\Tie[e=2]{12} \Tie[b=0.25,e=1.75]{10}
			\Tie[swap,b=0.25,e=1.75]{9} \Tie[swap,e=2]{7}
			\Barline
			\Note{1}{12/10/<9/7}
		\end{mousik}
	\end{center}
	
	\begin{lstlisting}[basicstyle=\ttfamily\small]
	\begin{mousik}[piano, piano-sep=2]
		\UpperStaff
		\Clef[octave=8] \TimeSig{4}{4}
		\MDots{*/1, , */3, } \Note{|-,=|,|-,=|}{1,2,3,4}
		\Note{4}{2}
		\Artic{^}{0} \Note{8}{0,1}
		\Tie[e=2]{1}
		\Barline
		\Note{1}{1}
		\Barline[t=|.]

		\LowerStaff			
		\Clef[t=4] \TimeSig{4}{4}
		\Note{2}{13/10/8} \Space[1.5]
		\MDot{13}\MDot{9}\MDot{7} \Note{4}{13/9/7} \Space[0.5]
		\Note{8}{12/10/<9/7}
		\Tie[e=2]{12} \Tie[b=0.25,e=1.75]{10}
		\Tie[swap,b=0.25,e=1.75]{9} \Tie[swap,e=2]{7}
		\Barline
		\Note{1}{12/10/<9/7}
	\end{mousik}
	\end{lstlisting}

It has some options:
	\begin{enumerate}[-]
		\item \textsl{color} changes the background color. Default is white.
		\item \textsl{indent} indents the first line. Default is 0, in cm.
		\item \textsl{long} changes the maximum width of the score. Default is 100.
		\item \textsl{hsep} changes the horizontal separation. Default is 8. Beams and parallel dot lists follow the same separation.
		\item \textsl{vsep} changes the vertical separation in case of an overflow. Default is 2, in cm.
		\item \textsl{single} draws a one-line staff, useful for percussion examples. Notes keep the usual absolute height system; height 6 lies on the line.
		\item \textsl{piano} draws an upper and a lower five-line staff. Use \verb|\UpperStaff| and \verb|\LowerStaff| to choose which one receives the following commands. Each staff keeps its own cursor, clef, and key.
		\item \textsl{piano-sep} changes the distance between the two piano staves. Default is 1.6, in cm.
		\item \textsl{piano-bars} chooses whether barlines in piano mode are \texttt{joined} across both staves or \texttt{separate}. Default is \texttt{joined}. The command advances only the active staff.
		\item \textsl{tikz} allows extra options for the outside \texttt{tikz} environment.
	\end{enumerate}

	\section{Available commands}
	
	\subsection{\texttt{\textbackslash Barline}}
	The \verb|\Barline| command prints a bar on the score. It has some options:
	
	\begin{enumerate}[-]
		\item \textsl{t} (type) is the type of bar. Default is \texttt{|}, the single bar.
		
		\begin{center}
			\begin{mousik}
				\Text{\ttfamily|}
				\Barline
				\Space[0.5]
				
				\Text{\ttfamily||}
				\Barline[t= ||]
				\Space[0.5]
				
				\Text{\ttfamily|.}
				\Barline[t= |.]
				\Space[0.5]
				
				\Text{\ttfamily|:}
				\Barline[t= |:]
				\Space[0.5]
				
				\Text{\ttfamily:|:}
				\Barline[t= :|:]
				\Space[0.5]
				
				\Text{\ttfamily:|}
				\Barline[t= :|]
				\Space[0.5]
				
				\Text{\ttfamily:}
				\Barline[t= :]
				\Space[0.5]
				
				\Text{\ttfamily(\string\Space)}
				\Space
			\end{mousik}
		\end{center}
		\item \textsl{xshift} moves the element horizontally (x axis). Default is 0, in cm.
		\item \textsl{yshift} moves the element vertically (y axis). Default is 0, in cm.
	\end{enumerate}
	
	The only way to end a line in the score is with a bar or a space. Any other way may cause visual errors (see subsection \ref{overflow}).
	
	\subsection{\texttt{\textbackslash Space}}
	The \verb|\Space| command is not only used when no bar is needed. It may also be used to input \textit{extra} space between symbols. The default space is 1, in centimeters, \textemdash which is the default space between symbols in general, so it gets added\textemdash~but it may be any number (see subsection \ref{space}).
	
	\begin{center}
		\begin{mousik}
			\Barline
			\Text{\hspace*{-55pt}\texttt{[-0.5]}}
			\Space[-0.5]
			
			\Barline
			\Text{\hspace*{-25pt}\texttt{[0]}}
			\Space[0]
			
			\Barline
			\Text{\hspace*{-14pt}\texttt{[0.5]}}
			\Space[0.5]
			
			\Barline
			\Text{\hspace*{-0.5pt}\texttt{[1]}}
			\Space[1]
			
			\Barline
			\Text{\hspace*{13pt}\texttt{[1.5]}}
			\Space[1.5]
			
			\Barline[t=|.]
		\end{mousik}
	\end{center}
	
	\subsection{\texttt{\textbackslash Clef}}
	The \verb|\Clef| command might be used at any moment on the score, although they are automatically printed if an overflow happens (see subsection \ref{overflow}). It has some options:
	\begin{enumerate}[-]
		\item \textsl{octave} prints an octave eight on the clef. If it is an 8, it prints it above the clef; if it is a -8, it prints it below the clef. Default is 0.
		\item \textsl{t} (type) is the type of clef. Default is 2 (the Treble Clef).
		\item \textsl{xshift} moves the element horizontally (x axis). Default is 0, in cm.
		\item \textsl{yshift} moves the element vertically (y axis). Default is 0, in cm.
	\end{enumerate}
	\begin{center}
		\begin{mousik}
			\Text{\quad\texttt{1}}
			\Clef[t=1]
			\Text{\quad\texttt{2}}
			\Clef[t=2]
			\Text{\quad\texttt{3}}
			\Clef[t=3]
			\Text{\quad\texttt{4}}
			\Clef[t=4]
			\Text{\quad\texttt{11}}
			\Clef[t=11]
			\Text{\quad\texttt{12}}
			\Clef[t=12]
			\Text{\quad\texttt{13}}
			\Clef[t=13]
			\Text{\quad\texttt{14}}
			\Clef[t=14]
			\Text{\quad\texttt{15}}
			\Clef[t=15]
			\Text{\quad\texttt{0}}
			\Clef[t=0]
			\Barline[t=|.]
		\end{mousik}
	\end{center}
	
%	The \verb|\Octave| command prints an eight on a previous clef. It has one argument: if it is an 8, it prints it above the clef; if it is a -8, it prints it below the clef.
	
	\subsection{\texttt{\textbackslash TimeSig}}
	Time signatures might be used at any moment. \verb|\TimeSig{2}{4}| will draw a 2 by 4 time signature. Any number or symbol can be written inside the brackets.
	Also \verb|\TimeSig{C}{}| will produce a \textit{common time} symbol and \verb+\TimeSig{C|}{}+ will produce an \textit{alla breve} symbol.
	\begin{center}
		\begin{mousik}
			\Clef
			
			\TimeSig{2}{4}
			\Space[0.5]
			\TimeSig{12}{8}
			\Space
			\TimeSig{2+3}{8}
			\Space
			
			\TimeSig{C}{}
			\Space[0.5]
			\TimeSig{C|}{}
			
			\Barline[t=|.]
		\end{mousik}
	\end{center}

	It has some options:
	\begin{enumerate}[-]
	\item \textsl{xshift} moves the element horizontally (x axis). Default is 0, in cm.
	\item \textsl{yshift} moves the element vertically (y axis). Default is 0, in cm.
	\end{enumerate}
	
	\subsection{Notes and rests}
	\subsubsection{\texttt{\textbackslash Note}}
	The \verb|\Note| command prints a note on the score. It accepts 2 compulsory arguments, as well as some options:
	\begin{enumerate}[-]
		\item \textsl{beam} chooses the width of the beam. Default is 1, in mm.
		\item \textsl{head} chooses the type of head. Default is . (round), but also x (cross) and o (hollow) are possible.
		\item \textsl{stem} chooses the height of the stem. Default is 5, in mm.
		\item \textsl{swap} prints the element upside down. Default is false, which means up if the height is less than 6, down otherwise.
		\item \textsl{tuplet} prints the number of a tuplet. The written number is calculated by default, but it can be assigned optionally: \texttt{tuplet=5}.
		\item \textsl{tuplet-bracket} draws a bracket around the tuplet number. Default is false.
		\item \textsl{tuplet-xshift} moves only the tuplet marking horizontally. Default is 0, in cm.
		\item \textsl{tuplet-yshift} moves only the tuplet marking vertically. Default is 0, in cm.
		\item \textsl{xshift} moves the element horizontally (x axis). Default is 0, in cm.
		\item \textsl{yshift} moves the element vertically (y axis). Default is 0, in cm.
	\end{enumerate}
	
	The first compulsory argument is the duration of the note.%, from one of these:% 1 (whole note / semibreve), 2 (half note / minim), 4 (quarter note / crotchet), 8 (eighth note / quaver), 16 (sixteenth note / semiquaver), 32 (thirty second note / demisemiquaver).
	
	\begin{center}
		\begin{mousik}\ttfamily
			\Clef
			\foreach \i in {1,2,4,8,16,32} {
				\Text[yshift=-0.5]{\i}
				\Note{\i}{5}
				\Back
				\Note[swap]{\i}{2}
			}
			\Barline[t=|.]
		\end{mousik}
	\end{center}
	
	The second argument is the absolute height. Note that the scale is in milimeters. For example, these are the notes from 0 to 9:
	
	\begin{center}
		\begin{mousik}\ttfamily
			\Clef
			\foreach \n in {0,...,9} {
				\Text{\n}
				\Note{4}{\n}
			}
			\Barline[t=|.]
		\end{mousik}
	\end{center}
	
	Heights separated by \texttt{/} correspond to chords: they belong to the same note event and are printed at the same x-position. Sometimes two heads need to be displaced to fit in a chord. For this, prefix the head that should move left with \texttt{<}.
	
	\begin{center}
		\begin{mousik}
			\Clef
			\TTT[-0.5]{Note\{1\}\{0/4/7\}}
			\Note{1}{0/4/7}
			\Space[2]
			\TTT[0.25]{Note\{1\}\{12/10/<9/7\}}
			\Note{1}{12/10/<9/7}
			\Barline[t=|.]
		\end{mousik}
	\end{center}
	
	The \verb|\Note| command also prints several notes tied together with a beam, if the second argument is a list of heights separated by commas. Two notes will be tied together with an oblique beam, but three or more will have a straight beam.%\todo{monotone triplets sliding beam}
	
%	The notes go upside down when their height (or maximum height) is bigger than 6. However, for manual control, the \verb|\Swap| command might be used \textit{before} the note.


	
	
	\begin{center}
		\begin{mousik}
			\Clef
			
			\TTT[-0.5]{Note[stem=6]\{16\}\{5,6\}}
			\Note[stem=6]{16}{5,6}
			\Space[1.5]
			
			\Space[0.5]\TTT[0.25]{Note[swap]\{32\}\{5,6\}}\Space[-0.5]
			\Note[swap]{32}{5,6}
			\Space[1.5]
			
			\Space[0.5]\TTT[-0.5]{Note[tuplet]\{8\}\{7,8,9\}}
			\Note[tuplet]{8}{7,8,9}
			
			\Barline[t=|.]
		\end{mousik}
	\end{center}
	
	Notes with different durations that are tied together have a different syntax. Instead of using 8, 16 and 32 for the duration, each note has to be referenced with a \texttt{-}, a \texttt{=} or a $\equiv$, respectively, and additional \texttt{|} might be needed for half the beam.
	
	\begin{center}
		\begin{mousik}
			\Clef
			
			\Space[2]
			\TTT{Note\{|$\equiv$,-,|=,=,=|,-,|=,$\equiv$|\}\{0,1,2,3,4,3,2,1\}}
			\Space[-2]
			\Note{|≡,-,|=,=,=|,-,|=,≡|}{0,1,2,3,4,3,2,1}
			
			\Barline[t=|.]
		\end{mousik}
	\end{center}

	To be able to write the $\equiv$ (which is the Unicode character U+2261) as a symbol on the .tex file, I usually copy and paste it wherever I need it. Nonetheless, an alternative keyboard-friendly input that is equally valid is using \texttt{/$\!$/$\!$/} instead.
	
	Additionally, spaces between notes from the same group might be useful \textemdash the default space is 0.5, in cm. 
	
	A space of 0.75 is obtained when a \texttt{!} is placed on both lists. A possible usage is when dealing with wide accidentals (see section \ref{acc}) or double dots (see section \ref{dot}).
	
	\begin{center}
		\begin{mousik}
			\Clef
			
			\Accs{,!,-2/3,}
			\Note{|-,!,=,=|}{3,!,3,3}
			
			\Accs{,!,-2/3,}
			\Note{|=,!,=,=|}{3,!,3,3}
			
			\Accs{,!,-2/3,}
			\Note{|≡,!,≡,≡|}{3,!,3,3}
			
			\Barline[t=|.]
		\end{mousik}
		\begin{mousik}
			\Clef
			
			\MDots{,**/3,!,*/3}
			\Note{|-,|=,!,-|}{3,3,!,3}
			
			\MDots{,**/3,!,*/3}
			\Note{|=,|≡,!,=|}{3,3,!,3}
			
			\MDots{,**/3,!,*/3}
			\Note{|≡,|=,!,≡|}{3,3,!,3}
			
			\Barline[t=|.]
		\end{mousik}
	\end{center}
	A space of 1 is obtained when a space is placed on both lists. A possible usage is when dealing with rests (see section \ref{rest}).
	\begin{center}
		\begin{mousik}
			\Clef
			
			\Note{|-, ,-,-|}{3, ,3,3}
			\Space[-2]\Rest[yshift=-0.2]{8}\Space[1]
			
			\Note{|=, ,=,=|}{3, ,3,3}
			\Space[-2]\Rest[yshift=-0.2]{16}\Space[1]
			
			\Note{|≡, ,≡,≡|}{3, ,3,3}
			\Space[-2]\Rest[yshift=-0.4]{32}\Space[1]
			
			\Barline[t=|.]
		\end{mousik}
	\end{center}

	\subsubsection{\texttt{\textbackslash Rest}}\label{rest}
	The \verb|\Rest| command prints a rest. It accepts its duration as an argument: 1, 2, 4, 8, 16 or 32.
	
	\begin{center}
		\begin{mousik}\ttfamily
			\Clef
			\foreach \i in {1,2,4,8,16,32} {
				\Text{\i}
				\Rest{\i}
			}
			\Barline[t=|.]
		\end{mousik}
	\end{center}

	It has some options:
	\begin{enumerate}[-]
		\item \textsl{multi} transforms the rest into a multimeasure rest \textemdash where the rest lasts an arbitrary amount of bars.
		
		\begin{center}
			\begin{mousik}\ttfamily
				\Clef
				\TimeSig{C}{}
				
				\Note{1}{4/8/-1}
				\Barline
				
				\Space[0.5]\TTT{Rest[multi]\{17\}}\Space[-0.5]
				\Rest[multi]{17}
				
				\Barline
				\Note{1}{4/9/0}
				
				\Barline[t=|.]
			\end{mousik}
		\end{center}
		
		\item \textsl{xshift} moves the element horizontally (x axis). Default is 0, in cm.
		\item \textsl{yshift} moves the element vertically (y axis). Default is 0, in cm.
	\end{enumerate}
	
	\subsubsection{\texttt{\textbackslash Back}}
	The \verb|\Back| command moves the horizontal cursor backwards. Its optional argument is the number of note positions to step backwards, with 1 as default. It is useful for superimposing independent voices, as well as for more complicated chords.
	
	\begin{center}
		\begin{mousik}
			\Clef
			
			\TTT{Note\{8\}\{5,4\}}
			\TTT[-0.5]{Back[2]}
			\TTT[-1]{Note\{4\}\{1,2\}}
			\Note{8}{5,4}
			\Back[2]
			\Note{4}{1,2}
			
			\Space[2]
			
			\TTT{Note\{8\}\{5,4\}}
			\TTT[-0.5]{Back}
			\TTT[-1]{Note\{4\}\{2\}}
			\Note{8}{5,4}
			\Back
			\Note{4}{2}
			
			\Space[2]
			
			\TTT{Note\{8\}\{5,4\}}
			\TTT[-0.5]{Back[2]}
			\TTT[-1]{Note\{4\}\{1\}}
			\TTT[-1.5]{Space[1]}
			\Note{8}{5,4}
			\Back[2]
			\Note{4}{1}
			\Space[0.5]
			
			\Barline[t=|.]
		\end{mousik}
	\end{center}

	\subsection{Keys and accidentals}
	
	\subsubsection{\texttt{\textbackslash Acc}}\label{acc}
	The \verb|Acc| command prints an accidental before a note. It accepts 2 arguments.
	
	The first argument is the type of accidental: a number ranging from -2 to 2. The flat $\flat$ symbol might also be called with a \texttt{b} and the sharp $\sharp$ symbol might be called with \texttt{\textbackslash\#}.\todo{only \# ?}
	
	\begin{center}
		\begin{mousik}
			\Clef	
			\foreach \a in {-2,-1.5,...,2} {
				\Text{\texttt{\a}}
				\ifthenelse{\equal{\a}{-1}}{\Text[yshift=-0.5]{\texttt{b}}}{}
				\ifthenelse{\equal{\a}{1}}{\Text[yshift=-0.5]{\texttt{\textbackslash\#}}}{}
				\Acc{\a}{5}
				\Note{4}{5}
			}
			\Barline[t=|.]
		\end{mousik}
	\end{center}

The second argument is the height of the symbol, which correspond to those of the notes.

It also has some options:
\begin{enumerate}[-]
	\item \textsl{xshift} moves the element horizontally (x axis). Default is 0, in cm.
	\item \textsl{yshift} moves the element vertically (y axis). Default is 0, in cm.
\end{enumerate}

When there are several notes, the \verb|\Accs| command might be useful. It accepts as an argument a list of pairs: type/height. Where there is no accidental, the spot shall be left empty.
	
\begin{center}
	\begin{mousik}
		\Clef
		
		\Space[0.5]
		\TTT{Accs\{-2/5, ,-1/0\}}
		\TTT[-0.5]{Note{8}{5,3,0}}
		\Space[-0.5]
		\Accs{-2/5, ,-1/0}
		\Note{8}{5,3,0}
		
		\Barline[t=|.]
	\end{mousik}
\end{center}
	
	\subsubsection{\texttt{\textbackslash Key}}
	The \verb|\Key| command prints the key at any moment on the score, although they are automatically printed if an overflow happens (see subsection \ref{overflow}).
	
	It accepts an argument: a positive whole number from 1 to 7 for sharps \sharp, and a negative whole number from -1 to -7 for flats \flat.
	
	\begin{center}
		\begin{mousik}
			\Clef
			\foreach \k in {-1,...,-7} {
				\Key{\k}
				\Barline
			}
		\end{mousik}
		
		\begin{mousik}
			\Clef	
			\foreach \k in {1,...,7} {
				\Key{\k}
				\Barline
			}
		\end{mousik}
	\end{center}

				\Note{1}{8}
				\Barline[t=|.]

	\subsection{Other symbols}
	
	\subsubsection{\texttt{\textbackslash MDot}}\label{dot}
	The \verb|\MDot| command prints any amount of dots in front of a note or rest. It accepts a compulsory argument: the height of the dot, which corresponds to those of the notes. %\todo{as an option}
	
	
	It has some options:
	\begin{enumerate}[-]
		\item \textsl{t} (type) accepts $**$ or $..$ to produce 2 dots. The default is $*$.
		\item \textsl{xshift} moves the element horizontally (x axis). Default is 0, in cm.
		\item \textsl{yshift} moves the element vertically (y axis). Default is 0, in cm.
	\end{enumerate}
	
	When there are several notes, the \verb|\MDots| command might be useful. It accepts as an argument a list of pairs: symbols/height, where symbols might be $*$ or $**$. Where there are no dots, the spot shall be left empty.
	
	\begin{center}
		\begin{mousik}		
			\Clef
			
			\TTT{MDot\{5\}}
			\TTT[-0.5]{Note\{4\}\{5\}}
			\MDot{5}
			\Note{4}{5}
			
			\Space[1.5]
			
			\TTT{MDot[t= **]\{7\}}
			\TTT[-0.5]{Rest\{8\}}
			\MDot[t= **]{7}
			\Rest{8}
			
			\Space[2.5]
			
			\TTT{MDots\{*/5, , **/3\}}
			\TTT[-0.5]{Note\{|=,-,=|\}\{5,2,3\}}
			
			\Space[-0.5]
			
			\MDots{*/5, , **/3}
			\Note{|=,-,=|}{5,2,3}
			
			\Space[0.5]
			
			\Barline[t=|.]
		\end{mousik}
	\end{center}
	
	\subsubsection{\texttt{\textbackslash Tie}}
	
	The \verb|\Tie| command draws a tie between two notes. It has a compulsory argument, the height of both notes, and some options:
	
	\begin{enumerate}[-]
		\item \textsl{angle} changes the angle in which it is drawn. Default is 20, in degrees.
		\item \textsl{b} (beginning) changes the starting point. Default is 0, in cm.
		\item \textsl{e} (end) changes the ending point. Default is 1, in cm.
	
	\begin{center}
		\begin{mousik}		
			\Clef
			\TimeSig{3}{4}
			
			\Rest{4}
			\Note{2}{6}
			\Tie[e=2]{6}
			
			\TTT{Tie[e=2]\{6\}}
			\Barline
			\Note{4}{6}
		
			\Rest{8}
			
			
			\Text{\qquad\quad\texttt{\textbackslash Tie\{4\}}}
			\Note{8}{4}
			\Tie{4}	
			\Note{4}{4}
			
			\Barline[t=|.]
		\end{mousik}
	\end{center}

	\item \textsl{swap} prints the element upside down. Default is false, which means like a \textit{u} if the height is less than 6, and like an \textit{n} otherwise. 
	\item \textsl{width} changes the line width. Default is 0.15, in mm.
	\item \textsl{xshift} moves the element horizontally (x axis). Default is 0, in cm.
	\item \textsl{yshift} moves the element vertically (y axis). Default is 0, in cm.
	\end{enumerate}

	\subsubsection{The \texttt{Slurred} environment}
	
	The \verb|Slurred| environment draws a slur between the notes placed inside. It has two arguments: the heights of both beginning and end notes.
	
	\begin{center}
		\begin{mousik}
			\Clef
			\Note{4}{6}
			\begin{Slurred}{6}{11}
				\foreach\i in {7,...,11}{\Note{4}{\i}}
			\end{Slurred}

			\Barline[t=|.]
		\end{mousik}
	\end{center}

	\subsubsection{The \texttt{Crescendo} and \texttt{Decrescendo} environments}
	
	The \verb|Crescendo| and \verb|Decrescendo| environments draw hairpins between the notes placed inside. Their options are:
	\begin{enumerate}[-]
		\item \textsl{height} moves the centre of the hairpin vertically. Default is 0. 
		\item \textsl{begin} and \textsl{end} set the full opening of the hairpin at its beginning and end, in cm. A crescendo defaults to \texttt{begin=0,end=0.4}. A decrescendo defaults to \texttt{begin=0.4,end=0}.
		\item \textsl{b} and \textsl{e} move the beginning and ending points horizontally from the first and last heads. Defaults are 0.1 and -0.1, in cm.
		\item \textsl{width} changes the line width. Default is 0.15, in mm.
		\item \textsl{xshift} moves the hairpin horizontally. Default is 0, in cm.
		\item \textsl{yshift} moves the hairpin vertically. Default is 0, in cm.
	\end{enumerate}
	
	A hairpin that continues after a line break should be written as two independent pieces. Give the first piece a chosen \textsl{end} opening and use the same value as \textsl{begin} on the next line.

	\begin{center}
		\begin{mousik}
			\Clef

			\begin{Crescendo}[height=-3]
				\foreach\i in {2,...,-1}{\Note{4}{\i}}
			\end{Crescendo}			

			\begin{Decrescendo}
				\foreach\i in {6,...,3}{\Note{4}{\i}}
			\end{Decrescendo}

			\Barline[t=|.]
		\end{mousik}
	\end{center}

	\begin{center}
		\begin{mousik}
			\Clef
			\begin{Crescendo}[end=0.24]
				\Note{4}{2}\Note{4}{3}\Note{4}{4}
			\end{Crescendo}
			\Space
		\end{mousik}
		
		\begin{mousik}
			\Clef
			\begin{Crescendo}[begin=0.24,end=0.4]
				\Note{4}{4}\Note{4}{5}\Note{4}{6}
			\end{Crescendo}
			\Space
		\end{mousik}
	\end{center}

	\subsubsection{\texttt{\textbackslash Artic} and \texttt{\textbackslash Symbol}}	
	The \verb|\Artic| command prints an articulation symbol on a successive note. It accepts two arguments. The first one is the type of articulation.

	\begin{center}
	\begin{mousik}
		\Clef
		
		\Text[yshift=-0.65]{Staccato}\ARTC{.}
		\Text[yshift=2.75]{Staccatissimo}\ARTIC{'}
		\Text[yshift=-0.65]{Accent}\ARTC{>}
		\Text[yshift=2.75]{Marcato}\ARTIC[\textasciicircum]{^}
		\Text[yshift=-0.65]{Tenuto}\ARTC{-}
		\Text[yshift=2.75]{Fermata}\ARTIC{(.)}
		\Text[yshift=-0.65]{Trill}\ARTC{+}
		\Text[yshift=2.75]{Mordent}\ARTIC[$\sim$]{~}
		\Text[yshift=-0.65]{Lower mordent}\ARTC[$\sim\!|$]{~|}
		\Text[yshift=2.75]{Turn}\ARTIC{?}
		
		\Barline[t=|.]
	\end{mousik}
	
	\begin{mousik}
		\Clef
		
		\Text[yshift=2.75]{Harmonic}\ARTIC{o}
		\Space
		\Text[yshift=2.75]{Up bow}\ARTIC{v}
		\Space
		\Text[yshift=2.75]{Down bow}\ARTIC{n}
		
		\Barline[t=|.]
	\end{mousik}
\end{center}

The second one is the height of the symbol, which corresponds to those of the notes \textemdash but it might or might not be the height of the corresponding note.

It has some options:
\begin{enumerate}[-]
	\item \textsl{xshift} moves the element horizontally (x axis). Default is 0, in cm.
	\item \textsl{yshift} moves the element vertically (y axis). Default is 0, in cm.
\end{enumerate}

When there are several notes, the \verb|\Artics| command might be useful. It accepts as an argument a list of pairs: symbols/height. Where there are no symbols, the spot shall be left empty.


The \verb|\Symbol| command is similar to the \verb|\Artic| command, but it only accepts the type of symbol and not the height. These are symbols that have a fixed position on the score.

\begin{center}
	\begin{mousik}
		\Clef
		
		\Text[yshift=-0.65]{Breath}
		\Text[yshift=-0.15]{\texttt{\{,\}}}
		\Symbol{,}\Space[1.5]
		
		\Text[yshift=-0.65]{Caesura}
		\Text[yshift=-0.15]{\texttt{\{/\}}}
		\Symbol{/}\Space[1.5]
		
		\Text[yshift=-0.65]{Segno}
		\Text[yshift=-0.15]{\texttt{\{s\textbackslash\%\}}}
		\Symbol{s\%}\Space[1.5]
		
		\Text[yshift=-0.65]{Simile}
		\Text[yshift=-0.15]{\texttt{\{\textbackslash\%\}}}
		\Symbol{\%}\Space[1.5]
		
		\Text[yshift=-0.65]{Coda}
		\Text[yshift=-0.15]{\texttt{\{o+\}}}
		\Symbol{o+}\Space[1.5]
		
		\Text[yshift=2.75]{Pedal}
		\Text[yshift=2.25]{\texttt{\{Ped\}}}
		\Symbol{Ped}\Space[1.5]
		
		\Text[yshift=2.75]{Lift Pedal}
		\Text[yshift=2.25]{\texttt{\{*\}}}
		\Symbol{*}\Space
		
		\Barline[t=|.]
	\end{mousik}
	\end{center}

It also has some options:
\begin{enumerate}[-]
	\item \textsl{xshift} moves the element horizontally (x axis). Default is 0, in cm.
	\item \textsl{yshift} moves the element vertically (y axis). Default is 0, in cm.
\end{enumerate}

	\subsection*{\sbs{overflow}Overflow of lines}
	The \textsf{mousik} package is thought to be used for small fragments of music. The environment has a maximum length allowed \textemdash which might be changed with the \textsl{length} option\textemdash~and whenever it is exceeded an overflow happens. The line is broken at that exact point and, if it does not coincide with a bar, something like this may happen:
	
	\begin{mousik}
		\Clef
		\Key{-3}
		\TimeSig{2}{4}
		\Note{8}{0,1}
		\Barline
		\Note{8}{2,3}
		\Barline
		\Note{8}{4,5}
		\Barline
		\Note{8}{6,7}
		\Barline
		\Note{8}{8,9}
	\end{mousik}%\todo{explain overflow}

	The best way to avoid the error is by introducing extra spaces manually. The overflow will also automatically print the previous clef and key.
	
	\subsection*{\sbs{space}How do spaces work?}
	
	Spaces serve as the manual progression of an invisible cursor during the printing.
	
	Most elements are separated by a distance of 1 cm, so a \verb|\Space| command that has an argument smaller than -1 will actually step backwards. A \verb|\Space| with a 0 as the argument does nothing.
	
	The \verb|\Space| command is truly relevant in this package. Not a lot of logic is internally implemented, so the user is supposed to adjust everything at their convenience.
	
	This is not to say that the package becomes too cumbersome to manage. For the general use I would say it is extremely user-friendly.
	
	\subsection*{\sbs{command}What if it does become too cumbersome: your own commands}
	\begin{multicols}{2}
		If a concrete rhythm is constantly used on a music piece, but the commands become increasingly long and tedious, the user might want to summarize it by creating their own vocabulary.

		\newcommand{\tct}[2][]{\Note[#1]{|=,=|,-|}{#2}}

			\ttc{7,8,9}

			\Barline[t= |.]
		\end{mousik}
	\end{multicols}

	\subsection*{\sbs{tikz}On your own: working with the \textsf{tikz} package}
	As stated in the introduction (section \ref{intro}), the \textsf{mousik} package is based on the \textsf{tikz} package. In fact, the \texttt{mousik} environment is a disguised version of a \texttt{tikzpicture} environment, but with some variables and a printed staff.
	
	This implies two separate things:
	\begin{enumerate}
		\item The mousik environment admits other commands inside, not just the commands explained in this text. For example, I might draw nodes, lines, or even a fractal behind my score:
	
	\begin{mousik}
		\Clef
		\Key{-3}
		\TimeSig[xshift=0.25]{C}{}
		
		\Rest{8}
		\Accs{,0/6}
		\Note{16}{7,6}
		\Note{8}{7,4}
		\Note{-,|=,=|}{5,7,6}
		\Note{8}{7,8}
		
		\Barline
		\Accs{,,0/6}
		\Note{-,|=,=|}{4,7,6}
		
		\begin{scope}[xshift=9cm,rotate=180]
			\draw [l-system={rule set={F -> F-F++F-F}, step=2pt, angle=60,
				axiom=F, order=4}] lindenmayer system;
		\end{scope}
	\end{mousik}
	

	\item The commands explained here might be used in a \texttt{tikzpicture} environment, and will appear with no staff. However, the command \verb|\Init| should be used at the beginning to avoid initialization errors.
	
	\begin{tikzpicture}
		\Init
		\Clef
		\Key{-3}
		\TimeSig[xshift=0.25]{C}{}
		
		\Rest{8}
		\Accs{,0/6}
		\Note{16}{7,6}
		\Note{8}{7,4}
		\Note{-,|=,=|}{5,7,6}
		\Note{8}{7,8}
		
		\Barline
		\Accs{,,0/6}
		\Note{-,|=,=|}{4,7,6}
	\end{tikzpicture}
	\end{enumerate}
