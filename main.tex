	\begin{abstract}
		This is a music-related package focused on writing music fragments. It works specially well with small examples, such as excerpts for theoretical articles. It is easier than other music writing methods in \LaTeX{} because it is based on the \textsf{tikz} package.

	\section{Introduction}
	There are already several ways to set music using \LaTeX. As stated by the \textsf{abc} package, ``\textit{notably MusixTEX and Lilypond}'', as well as \textsf{abc} per se.
	Some of them are too difficult to use for not too complicated music; others do not work at all.
	
	The \textsf{mousik} package is perfect for short, one line music fragments. It may be used for longer scores, but there are more adaptable and lighter packages than this one. However, in spite of its compactness, the package is quite complete and versatile, but easy to learn and use.
	
	\section{The \texttt{mousik} environment}
	The way to draw a score is by means of the \texttt{mousik} environment. For a longer example, see section \ref{example}.

	\section{Available commands}
	
	\subsection{\texttt{\textbackslash Bar}}
	The \verb|\Bar| command prints a bar on the score. It has an optional argument depending on the type of bar, with default \texttt{|}, the single bar (\verb+\Bar+ = \verb+\Bar[|]+).
	
	\begin{center}
		\begin{mousik}
			\Text{\ttfamily[|]}
			\Bar
			\Space[1]
			
			\Text{\ttfamily[||]}
			\Bar[||]
			\Space[1]
			
			\Text{\ttfamily[|.]}
			\Bar[|.]
			\Space[1]
			
			\Text{\ttfamily[|:]}
			\Bar[|:]
			\Space[1]
			
			\Text{\ttfamily[:|:]}
			\Bar[:|:]
			\Space[1]
			
			\Text{\ttfamily[:|]}
			\Bar[:|]
			\Space[1]
			
			\Text{\ttfamily[:]}
			\Bar[:]
			\Space[1]
			
			\TTT{Space}
			\Space
		\end{mousik}
	\end{center}
	
	The only way to end a line in the score is with a bar or a space. Any other way may cause visual errors (see subsection \ref{overflow}).
	
	\subsection{\texttt{\textbackslash Space}}
	The \verb|\Space| command is not only used when no bar is needed. It may also be used to input \textit{extra} space between symbols. The default space is 2 (which is the default space between symbols in general), but it may be any whole number (see subsection \ref{space}).
	
	\begin{center}
		\begin{mousik}
			\Bar
			\Text{\hspace*{-41pt}\texttt{[-1]}}
			\Space[-1]
			
			\Bar
			\Text{\hspace*{-27.5pt}\texttt{[0]}}
			\Space[0]
			
			\Bar
			\Text{\hspace*{-14pt}\texttt{[1]}}
			\Space[1]
			
			\Bar
			\Text{\hspace*{-0.5pt}\texttt{[2]}}
			\Space
			
			\Bar
			\Text{\hspace*{13pt}\texttt{[3]}}
			\Space[3]
			
			\Bar[|.]
		\end{mousik}
	\end{center}


	
	\subsection{\texttt{\textbackslash Clef}}
	The \verb|\Clef| command might be used at any moment on the score, although they are automatically printed if an overflow happens (see subsection \ref{overflow}). It has some options:
	\begin{enumerate}[-]
		\item \textsl{octave} prints an octave eight on the clef. If it is an 8, it prints it above the clef; if it is a -8, it prints it below the clef. Default is 0.
		\item \textsl{t} (type) is the type of clef. Default is 2 (the Treble Clef).
	\end{enumerate}
	\begin{center}
		\begin{mousik}
			\Text{\quad\texttt{1}}
			\Clef[t=1]
			\Text{\quad\texttt{2}}
			\Clef[t=2]
			\Text{\quad\texttt{3}}
			\Clef[t=3]
			\Text{\quad\texttt{4}}
			\Clef[t=4]
			\Text{\quad\texttt{11}}
			\Clef[t=11]
			\Text{\quad\texttt{12}}
			\Clef[t=12]
			\Text{\quad\texttt{13}}
			\Clef[t=13]
			\Text{\quad\texttt{14}}
			\Clef[t=14]
			\Text{\quad\texttt{15}}
			\Clef[t=15]
			\Text{\quad\texttt{0}}
			\Clef[t=0]
			\Bar[|.]
		\end{mousik}
	\end{center}

	\subsection{\texttt{\textbackslash TimeSig}}
	Time signatures might be used at any moment. \verb|\TimeSig{2}{4}| will draw a 2 by 4 time signature. Any number or symbol can be written inside the brackets.
	Also \verb|\TimeSig{C}{}| will produce a \textit{common time} symbol and \verb+\TimeSig{C|}{}+ will produce an \textit{alla breve} symbol.
	\begin{center}
		\begin{mousik}
			\Clef
			
			\TimeSig{2}{4}
			\Space[1]
			\TimeSig{12}{8}
			\Space[2]
			\TimeSig{2+3}{8}
			\Space[2]
			
			\TimeSig{C}{}
			\Space[1]
			\TimeSig{C|}{}
			
			\Bar[|.]
		\end{mousik}
	\end{center}
	
	\subsection{Notes and rests}
	\subsubsection{\texttt{\textbackslash Note}}
	The \verb|\Note| command prints a note on the score. It accepts 2 compulsory arguments, as well as some options:
	\begin{enumerate}[-]
		\item \textsl{beam} chooses the width of the beam. Default is 1 (mm).
		\item \textsl{head} chooses the type of head. Default is . (round), but also x (cross) and o (hollow) are possible.
		\item \textsl{stem} chooses the height of the stem. Default is 0.3.
		\item \textsl{swap} prints the note upside down. Default is false, which means up if the height is less than 6, down otherwise.
%		\item \textsl{tuplet} prints the number of a tuplet. %It has two arguments, an optional one and a compulsory one. The optional one is the written number, which is automatically calculated by default. The compulsory one is the height.
%		\todo[color=red]{bar on tuplet, fix height}
	\end{enumerate}
	
	The first compulsory argument is the duration of the note.%, from one of these:% 1 (whole note / semibreve), 2 (half note / minim), 4 (quarter note / crotchet), 8 (eighth note / quaver), 16 (sixteenth note / semiquaver), 32 (thirty second note / demisemiquaver).
	
	\begin{center}
		\begin{mousik}\ttfamily
			\Clef
			\foreach \i in {1,2,4,8,16,32} {
				\Text[-0.5]{\i}
				\Note{\i}{5}
				\Chord
				\Note[swap]{\i}{2}
			}
			\Bar[|.]
		\end{mousik}
	\end{center}
	
	The second argument is the absolute height. For example, these are the notes from 0 to 9:
	
	\begin{center}
		\begin{mousik}\ttfamily
			\Clef
			\foreach \n in {0,...,9} {
				\Text{\n}
				\Note{4}{\n}
			}
			\Bar[|.]
		\end{mousik}
	\end{center}\todo[color=orange]{\href{https://tex.stackexchange.com/questions/12010/how-can-i-invert-a-clip-selection-within-tikz}{remove white}}
	
	The \verb|\Note| command might also print several notes tied together with a beam, if the second argument is a list of durations separated by commas. Two notes will be tied together with an oblique beam, but three or more will have a straight beam.%\todo[color=cyan]{monotone triplets sliding beam}

	\subsubsection{\texttt{\textbackslash Rest}}
	The \verb|\Rest| command prints a rest. It accepts its duration as an argument: 1, 2, 4, 8, 16 or 32.
	
	\begin{center}
		\begin{mousik}\ttfamily
			\Clef
			\foreach \i in {1,2,4,8,16,32} {
				\Text{\i}
				\Rest{\i}
			}
			\Bar[|.]
		\end{mousik}
	\end{center}

	If a multimeasure rest is needed \textemdash where the rest lasts an arbitrary amount of bars\textemdash~an optional argument \textsl{multi} might be used.
	
	\begin{center}
		\begin{mousik}\ttfamily
			\Clef
			\TimeSig{C}{}
			
			\Note{1}{4}	\Chord	\Note{1}{8}	\Chord	\Note{1}{-1}
			\Bar
			
			\Space[1]\TTT{Rest[multi]\{17\}}\Space[-1]
			\Rest[multi]{17}
			
			\Bar
			\Note{1}{4}	\Chord	\Note{1}{9}	\Chord	\Note{1}{0}
			
			\Bar[|.]
		\end{mousik}
	\end{center}

	\subsection{Keys and accidentals}
	
	\subsubsection{\texttt{\textbackslash Acc}}
	The \verb|Acc| command prints an accidental before a note. It accepts 2 arguments.
	
	The first argument is the type of accidental: a number ranging from -2 to 2. The flat $\flat$ symbol might also be called with a \texttt{b} and the sharp $\sharp$ symbol might be called with \texttt{\textbackslash\#}.\todo[color=yellow]{only \# ?} \todo[color=orange]{weird width bb}
	
	\begin{center}
		\begin{mousik}
			\Clef	
			\foreach \a in {-2,-1.5,...,2} {
				\Text{\texttt{\a}}
				\MString{\a}{-1}{\Text[-0.5]{\texttt{b}}}
				\MString{\a}{1}{\Text[-0.5]{\texttt{\textbackslash\#}}}
				\Acc{\a}{5}
				\Note{4}{5}
			}
			\Bar[|.]
		\end{mousik}
	\end{center}

The second argument is the height of the symbol.

When there are several notes, the \verb|\Accs| command might be useful. It accepts as an argument a list of pairs: type/height. Where there is no accidental, the spot shall be left empty.
	
\begin{center}
	\begin{mousik}
		\Clef
		
		\Space[1]
		\TTT{Accs\{-2/5, ,-1/0\}}
		\TTT[-0.5]{Note\{5,3,0\}}
		\Space[-1]
		
		\Accs{-2/5, ,-1/0}
		\Note{8}{5,3,0}
		
		\Bar[|.]
	\end{mousik}
\end{center}
	
	\subsubsection{\texttt{\textbackslash Key}}
	The \verb|\Key| command prints the key at any moment on the score, although they are automatically printed if an overflow happens (see subsection \ref{overflow}).
	
	It accepts an argument: a positive whole number from 1 to 7 for sharps \sharp, and a negative whole number from -1 to -7 for flats \flat.
	
	\begin{center}
		\begin{mousik}
			\Clef
			\foreach \k in {-1,...,-7} {
				\Key{\k}
				\Bar
			}
		\end{mousik}
		
		\begin{mousik}
			\Clef	
			\foreach \k in {1,...,7} {
				\Key{\k}
				\Bar
			}
		\end{mousik}
	\end{center}

	\subsection{Other symbols}
	
	\subsubsection{\texttt{\textbackslash Dot}}
	
	The \verb|\Dot| command prints any amount of dots in front of a note or rest. It accepts an optional argument and a compulsory argument. %\todo{as an option}
	
	The default number of dots is 1, but, as an optional argument, $**$ will produce 2 dots. The second, compulsory argument is the height of the dot.
	
	When there are several notes, the \verb|\Dots| command might be useful. It accepts as an argument a list of pairs: symbols/height, where symbols might be $*$ or $**$. Where there are no dots, the spot shall be left empty.
	
	\begin{center}
		\begin{mousik}		
			\Clef
			
			\TTT{Dot\{5\}}
			\TTT[-0.5]{Note\{4\}\{5\}}
			\Dot{5}
			\Note{4}{5}
			
			\Space[3]
			
			\TTT{Dot[**]\{7\}}
			\TTT[-0.5]{Rest\{8\}}
			\Dot[**]{7}
			\Rest{8}
			
			\Space[5]
			
			\TTT{Dots\{*/5, , **/3\}}
			\TTT[-0.5]{Note\{|=,-,=|\}\{5,2,3\}}
			
			\Space[-1]
			
			\Dots{*/5, , **/3}
			\Note{|=,-,=|}{5,2,3}
			
			\Space[1]
			
			\Bar[|.]
		\end{mousik}
	\end{center}
	
	\subsubsection{\texttt{\textbackslash Tie}}
	
	The \verb|\Tie| command draws a tie between two notes. It has a compulsory argument, the height of both notes, and an optional one: the separation between the two notes. The default value is 1.
	
	\begin{center}
		\begin{mousik}		
			\Clef
			\TimeSig{3}{4}
			
			\Rest{4}
			\Note{2}{6}
			\Tie[3]{6}
			
			\TTT{Tie[3]\{6\}}
			\Bar
			\Note{4}{6}
		
			\Rest{8}
			
			
			\Text{\qquad\quad\texttt{\textbackslash Tie\{4\}}}
			\Note{8}{4}
			\Tie{4}			
			\Note{4}{4}
			
			\Bar[|.]
		\end{mousik}
	\end{center}

	The \verb|Slurred| environment draws a slur between the notes placed inside. It has two arguments: the heights of both beginning and end notes.

		\Text[2.75]{Harmonic}\ARTIC{o}
		\Space
		\Text[2.75]{Up bow}\ARTIC{v}
		\Space
		\Text[2.75]{Down bow}\ARTIC{n}
		
		\Bar[|.]
	\end{mousik}
\end{center}

The second one is the height of the symbol, which might or might not be the height of the corresponding note.

When there are several notes, the \verb|\Artics| command might be useful. It accepts as an argument a list of pairs: symbols/height. Where there are no symbols, the spot shall be left empty.


The \verb|\Symbol| command is similar to the \verb|\Artic| command, but it only accepts the type of symbol and not the height. These are symbols that have a fixed position on the score.

\begin{center}
	\begin{mousik}
		\Clef
		
		\Text[-0.65]{Breath}
		\Text[-0.15]{\texttt{\{,\}}}
		\Symbol{,}\Space[3]
		
		\Text[-0.65]{Caesura}
		\Text[-0.15]{\texttt{\{/\}}}
		\Symbol{/}\Space[3]
		
		\Text[-0.65]{Segno}
		\Text[-0.15]{\texttt{\{s\textbackslash\%\}}}
		\Symbol{s\%}\Space[3]
		
		\Text[-0.65]{Simile}
		\Text[-0.15]{\texttt{\{\textbackslash\%\}}}
		\Symbol{\%}\Space[3]
		
		\Text[-0.65]{Coda}
		\Text[-0.15]{\texttt{\{o+\}}}
		\Symbol{o+}\Space[3]
		
		\Text[2.75]{Pedal}
		\Text[2.25]{\texttt{\{Ped\}}}
		\Symbol{Ped}\Space[3]
		
		\Text[2.75]{Lift Pedal}
		\Text[2.25]{\texttt{\{*\}}}
		\Symbol{*}\Space
		
		\Bar[|.]
	\end{mousik}
	\end{center}



	\subsection{\texttt{\textbackslash Text} and \texttt{\textbackslash Dynamics}}
	The \verb|\Text| command allows the printing of any text string. It has a compulsory argument, but also an optional one where the user may choose the height of the string: \verb|\Text[2]{\it rit.}|.
	
	To write anything in the usual font of dynamics, the \verb|\Dynamics| command will work the same: \verb|\Dynamics[-0.5]{pp}|.
	\begin{center}
		\begin{mousik}
			\Clef
			\Key{-3}
			\TimeSig{2}{4}
			
			\Text{C}
			\Note{4}{0}
			
			\Note{8}{1,2}		
			\Chord
			\Text{E}
			\Space
			
			\Bar
			
			\Text[2]{\it rit.}
			\Note{8}{3,4}
			
			\Dynamics[-0.5]{pp}
			\Note{4}{-3}
			
			\Bar[|.]
		\end{mousik}
	\end{center}

\subsection{\texttt{\textbackslash Tempo}}
The \verb|\Tempo| command prints a metronome tempo indicator. It has two arguments: the duration of the note and the numerical tempo which will be printed.

\begin{center}
\begin{mousik}
	\Clef
	\Tempo{8}{120}
	\Note{4}{2}
	\Note{4}{3}
	\Bar
	\Tempo[-0.1]{2}{60}
	\Note{4}{4}
	\Rest{4}
	
	\Bar[|.]
\end{mousik}
\end{center}

	\subsection*{\sbs{overflow}Overflow of lines}
	The \textsf{mousik} package is thought to be used for small fragments of music. The environment has a maximum length allowed, and whenever it is exceeded an overflow happens. The line is broken at that exact point and, if it does not coincide with a bar, something like this may happen:
	
	\begin{mousik}
		\Clef
		\Key{-3}
		\TimeSig{2}{4}
		\Note{8}{0,1}
		\Bar
		\Note{8}{2,3}
		\Bar
		\Note{8}{4,5}
		\Bar
		\Note{8}{6,7}
		\Bar
		\Note{8}{8,9}
	\end{mousik}%\todo[color=yellow]{explain overflow}

	The best way to avoid the error is by introducing extra spaces manually. The overflow will also automatically print the previous clef and key.
