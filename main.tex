	\begin{abstract}
		This is a music-related package focused on writing music fragments. It works specially well with small examples, such as excerpts for theoretical articles. It is easier than other music writing methods in \LaTeX{} because it is based on the \textsf{tikz} package.

			\textbf{Keywords}
		\end{center}
		
		\textit{mousik, music, music theory, music notation, music writing, score, sheet, tikz diagram, bar, clef, time signature, note, symbol, rest, dot, chord, accidental, sharp, flat, natural, key}
	\end{abstract}

	\section{Introduction}
	There are already several ways to set music using \LaTeX. As stated by the \textsf{abc} package, ``\textit{notably MusixTEX and Lilypond}'', as well as \textsf{abc} per se.
	Some of them are too difficult to use for not too complicated music; others do not work at all.
	
	The \textsf{mousik} package is perfect for short, one line music fragments. It may be used for longer scores, but there are more adaptable and lighter packages than this one. However, in spite of its compactness, the package is quite complete and versatile, but easy to learn and use.

	\section{The \texttt{mousik} environment}
	The way to draw a score is by means of the \texttt{mousik} environment.
	
	\begin{center}
		\begin{mousik}
			\Clef{2}
			\Key{-3}
			\TimeSig{4}{4}
			
			\Note{1}{5}
			\Chord
			
			\Acc{0}{9}
			\Note{1}{9}
			\Bar
			
			\Rest{8}
			\Note{8}{5,2,5}
			\Bar[|.]
		\end{mousik}
	\end{center}
	
	\begin{lstlisting}[basicstyle=\ttfamily]
		  \begin{mousik}
			\Clef{2}
			\Key{-3}
			\TimeSig{4}{4}
			
			\Note{1}{5}
			\Chord
			\Acc{0}{9}
			\Note{1}{9}
			\Bar
			
			\Rest{8}
			\Note{8}{5,2,5}
			\Bar[|.]
		  \end{mousik}
	\end{lstlisting}

	\section{Available commands}
	
	\subsection{\texttt{\textbackslash Bar}}
	The \verb|\Bar| command prints a bar on the score. It has an optional argument depending on the type of bar, with default \texttt{|}, the single bar (\verb+\Bar = \Bar[|]+).
	
	\begin{center}
		\begin{mousik}
%			\TTT{Bar}
			\Text{\ttfamily[|]}
			\Bar
			\Space[1]
			
%			\TTT{Bar[||]}
			\Text{\ttfamily[||]}
			\Bar[||]
			\Space[1]
			
%			\TTT{Bar[|.]}
			\Text{\ttfamily[|.]}
			\Bar[|.]
			\Space[1]
			
%			\TTT{Bar[|:]}
			\Text{\ttfamily[|:]}
			\Bar[|:]
			\Space[1]
			
%			\TTT{Bar[:|:]}
			\Text{\ttfamily[:|:]}
			\Bar[:|:]
			\Space[1]
			
%			\TTT{Bar[:|]}
			\Text{\ttfamily[:|]}
			\Bar[:|]
			\Space[1]
			
			\TTT{Space}
			\Space
		\end{mousik}
	\end{center}
	
	The only way to end a line in the score is with a bar or a space. Any other way may cause visual errors (see subsection \ref{overflow}).
	
	\subsection{\texttt{\textbackslash Space}}
	The \verb|\Space| command is not only used when no bar is needed. It may also be used to input \textit{extra} space between symbols. The default space is 2 (which is the default space between symbols in general), but it may be any whole number (see subsection \ref{space}).
	
	\begin{center}
		\begin{mousik}
			\Bar
%			\Text{\hspace*{-40pt}\texttt{\textbackslash Space[-1]}}
			\Text{\hspace*{-41pt}\texttt{[-1]}}
			\Space[-1]
			
			\Bar
%			\Text[-0.5]{\hspace*{-25pt}\texttt{\textbackslash Space[0]}}
			\Text{\hspace*{-27.5pt}\texttt{[0]}}
			\Space[0]
			
			\Bar
%			\Text{\hspace*{-10pt}\texttt{\textbackslash Space[1]}}
			\Text{\hspace*{-14pt}\texttt{[1]}}
			\Space[1]
			
			\Bar
%			\Text{\hspace*{10pt}\texttt{\textbackslash Space}}
			\Text{\hspace*{-0.5pt}\texttt{[2]}}
			\Space
			
			\Bar
%			\Text{\hspace*{20pt}\texttt{\textbackslash Space[3]}}
			\Text{\hspace*{13pt}\texttt{[3]}}
			\Space[3]
			
			\Bar[|.]
		\end{mousik}
	\end{center}
	
	\subsection{\texttt{\textbackslash Clef}}
	Clefs might be used at any moment on the score, although they are automatically printed if an overflow happens (see subsection \ref{overflow}).
	
	\begin{itemize}
		\item \verb|\Clef{1}| and \verb|\Clef{2}| are Treble Clefs in the first and second lines.
		\item \verb|\Clef{3}| and \verb|\Clef{4}| are Bass Clefs in the third and fourth lines.
		\item \verb|\Clef{11}|, \verb|\Clef{12}|, \verb|\Clef{13}|, \verb|\Clef{14}| and \verb|\Clef{15}| are Alto Clefs in each of the five lines.
	\end{itemize}
	
	\begin{center}
		\begin{mousik}
			\Text{\quad\texttt{1}}
			\Clef{1}
			\Text{\quad\texttt{2}}
			\Clef{2}
			\Text{\quad\texttt{3}}
			\Clef{3}
			\Text{\quad\texttt{4}}
			\Clef{4}
			\Text{\quad\texttt{11}}
			\Clef{11}
			\Text{\quad\texttt{12}}
			\Clef{12}
			\Text{\quad\texttt{13}}
			\Clef{13}
			\Text{\quad\texttt{14}}
			\Clef{14}
			\Text{\quad\texttt{15}}
			\Clef{15}
			\Bar[|.]
		\end{mousik}
	\end{center}
	
	\subsection{\texttt{\textbackslash TimeSig}}
	Time signatures might be used at any moment. \verb|\TimeSig{2}{4}| will draw a 2 by 4 time signature. Any number or symbol can be written inside the brackets.
	Also \verb|\TimeSig{C}{}| will produce a \textit{common time} symbol and \verb+\TimeSig{C|}{}+ will produce an \textit{alla breve} symbol.
	\begin{center}
		\begin{mousik}
			\Clef{2}
			
			\TimeSig{2}{4}
			\TimeSig{12}{8}
			\Space[1]
			\TimeSig{2+3}{8}
			\Space[1]
			
			\TimeSig{C}{}
			\TimeSig{C|}{}
			
			\Bar[|.]
		\end{mousik}
	\end{center}
	
	\subsection{Notes and rests}
	\subsubsection{\texttt{\textbackslash Note}}
	The \verb|\Note| command prints a note on the score. It accepts 2 arguments.
	
	The first argument is the duration of the note, from one of these:% 1 (whole note / semibreve), 2 (half note / minim), 4 (quarter note / crotchet), 8 (eighth note / quaver), 16 (sixteenth note / semiquaver), 32 (thirty second note / demisemiquaver).
	
	\begin{center}
		\begin{mousik}\ttfamily
			\Clef{2}
			\foreach \i in {1,2,4,8,16,32} {
				\Text[-0.5]{\i}
				\Note{\i}{5}
				\Chord
				\Swap\Note{\i}{2}
			}
			\Bar[|.]
		\end{mousik}
	\end{center}
	
	The second argument is the absolute height. For example, these are the notes from 0 to 9:
	
	\begin{center}
		\begin{mousik}\ttfamily
			\Clef{2}
			\foreach \n in {0,...,9} {
				\Text{\n}
				\Note{4}{\n}
			}
			\Bar[|.]
		\end{mousik}
	\end{center}
	
	The \verb|\Note| command might also print several notes tied together with a beam. Two notes will be tied together with an oblique beam, but three or more will have a straight beam.\todo[color=yellow]{monotone triplets sliding beam}
	
	\begin{center}
		\begin{mousik}
			\Clef{2}
			\Note{16}{5,6}
			\Swap\Note{32}{5,6}
			\Note{8}{7,8,9}
			\Grupetto{-5}
			
			\Bar[|.]
		\end{mousik}
	\end{center}

	The notes go upside down when their height (or maximum height) is bigger than 6. However, for manual control, the \verb|\Swap| command might be used before the note, as seen above in the second group.
	
	To write the grupetto number of a tuplet, the \verb|\Grupetto| command might be used \textit{after} the note. It has two arguments, an optional one and a compulsory one. The optional one is the written number, which is automatically calculated by default. The compulsory one is the height: \verb|\Grupetto{-5}|.\todo[color=orange!50]{bar on grupetto}

	\subsubsection{\texttt{\textbackslash Rest}}
	The \verb|\Rest| command prints a rest. It accepts its duration as an argument: 1, 2, 4, 8, 16 or 32.
	
	\begin{center}
		\begin{mousik}\ttfamily
			\Clef{2}
			\foreach \i in {1,2,4,8,16,32} {
				\Text{\i}
				\Rest{\i}
			}
			\Bar[|.]
		\end{mousik}
	\end{center}
	
	\subsubsection{\texttt{\textbackslash Chord}}
	
	Chords may be obtained by means of the \verb|\Chord| command. It accepts an optional argument: the number of notes to step backwards \textemdash mostly for the \verb|\Note| command\textemdash\ with 1 as default.
	
	The best way to use it is to call the \verb|\Note| command with the highest notes; then call the \verb|\Chord| command; then call the \verb|\Note| command with the duration 4 of a quarter note, to print them on top.
	
	If the stem needs to be longer, the user may need the \verb|\Enlarge| command, which accepts as arguments the 2 heights of both notes.
	
	\begin{center}
		\begin{mousik}
			\Clef{2}
			
			\TTT{Note\{1\}\{6\}}
			\TTT[-0.5]{Chord}
			\TTT[-1]{Note\{1\}\{4\}}
			\Note{1}{6}
			\Chord
			\Note{1}{4}
			
			\Space[5]	
			
			\TTT{Swap\textbackslash Note\{16\}\{7\}}
			\TTT[-0.5]{Chord}
			\TTT[-1]{Swap\textbackslash Enlarge\{7\}\{0\}}
			\TTT[-1.5]{Note\{4\}\{0\}}
			\Swap\Note{16}{7}
			\Chord
			\Swap\Enlarge{7}{0}
			\Note{4}{0}
			
			\Bar[|.]
		\end{mousik}
	\end{center}
		
	For extreme uses of the command, extra \verb|\Space| commands might be needed, as seen here:
	
	\begin{center}
		\begin{mousik}
			\Clef{2}
			
			\TTT{Note\{8\}\{5,4\}}
			\TTT[-0.5]{Chord[2]}
			\TTT[-1]{Note\{4\}\{1,2\}}
			\Note{8}{5,4}
			\Chord[2]
			\Note{4}{1,2}
			
			\Space[4]
			
			\TTT{Note\{8\}\{5,4\}}
			\TTT[-0.5]{Chord}
			\TTT[-1]{Note\{4\}\{2\}}
			\Note{8}{5,4}
			\Chord
			\Note{4}{2}
			
			\Space[4]
			
			\TTT{Note\{8\}\{5,4\}}
			\TTT[-0.5]{Chord[2]}
			\TTT[-1]{Note\{4\}\{1\}}
			\TTT[-1.5]{Space[1]}
			\Note{8}{5,4}
			\Chord[2]
			\Note{4}{1}
			\Space[1]
			
			\Bar[|.]
		\end{mousik}
	\end{center}\todo[color=green]{maybe fix this}

	\subsection{Keys and accidentals}
	
	\subsubsection{\texttt{\textbackslash Acc}}
	The \verb|Acc| command prints an accidental \textit{before} a note. It accepts 2 arguments.
	
	The first argument is the type of accidental:
	\begin{multicols}{2}
		\begin{itemize}
			\item -2 for the \doubleflat\ double flat symbol.
			\item -1 for the \flat\ flat symbol.
			\item 0 for the \natural\ natural symbol.
			\item 1 for the \sharp\ sharp symbol.
			\item 2 for the \doublesharp\ double sharp symbol.
		\end{itemize}
	\end{multicols}

	The second argument is the height of the symbol.
	
	\begin{center}
		\begin{mousik}
			\Clef{2}	
			\foreach \a in {-2,-1,0,1,2} {
				\Text{\texttt{\a}}
				\Acc{\a}{5}
				\Note{4}{5}
			}
			\Bar[|.]
		\end{mousik}
	\end{center}

When there are several notes, the \verb|\Accs| command might be useful. It accepts as an argument a list of pairs: type/height. Where there is no accidental, the spot shall be left empty.
	
\begin{center}
	\begin{mousik}
		\Clef{2}
		\Space[1]
		\TTT{Accs\{-2/5, ,-1/0\}}
		\TTT[-0.5]{Note\{5,3,0\}}
		\Space[-1]
		
		\Accs{-2/5, ,-1/0}
		\Note{8}{5,3,0}
		
		\Bar[|.]
	\end{mousik}
\end{center}
	
	\subsubsection{\texttt{\textbackslash Key}}
	The \verb|\Key| command prints the key at any moment on the score, although they are automatically printed if an overflow happens (see subsection \ref{overflow}).
	
	It accepts an argument: a positive whole number from 1 to 7 for sharps \sharp, and a negative whole number from -1 to -7 for flats \flat.
	
	\begin{center}
		\begin{mousik}
			\Clef{2}
			\foreach \k in {-1,...,-7} {
				\Key{\k}
				\Bar
			}
		\end{mousik}
		
		\begin{mousik}
			\Clef{2}	
			\foreach \k in {1,...,7} {
				\Key{\k}
				\Bar
			}
		\end{mousik}
	\end{center}
	
	\subsubsection{\texttt{\textbackslash NoKey}}
	The \verb|\NoKey| command is the same as the \verb|\Key| command, but it prints naturals \natural\ instead of sharps or flats.
	
	\begin{center}
		\begin{mousik}
			\Clef{2}
			\foreach \k in {-1,...,-7} {
				\NoKey{\k}
				\Bar
			}
		\end{mousik}
		
		\begin{mousik}
			\Clef{2}	
			\foreach \k in {1,...,7} {
				\NoKey{\k}
				\Bar
			}
		\end{mousik}
	\end{center}
	
	Be careful: the \verb|\Key| and \verb|\NoKey| commands are affected by the current clef! Nonetheless, other commands such as \verb|\Note| or \verb|\Acc| are not affected and need absolute height values.
	
	\begin{multicols}{2}
		\begin{center}
			\begin{mousik}
				\Clef{4}
				\Key{1}
				\TimeSig{C|}{}
				
				\Acc{0}{8}
				\Note{1}{8}
				\Bar[|.]
			\end{mousik}
		\end{center}
		\columnbreak
		
	\begin{lstlisting}[basicstyle=\ttfamily]
  \begin{mousik}
	\Clef{4}
	\Key{1}
	\TimeSig{C|}{}
	
	\Acc{0}{8}
	\Note{1}{8}
	\Bar[|.]
  \end{mousik}
\end{lstlisting}
	\end{multicols}
	
	\subsection[Other symbols]{Other symbols: dots, ties, slurs and text}
	
	\subsubsection{\texttt{\textbackslash Dot}}
	
	The \verb|\Dot| command prints any amount of dots in front of a note or rest. It accepts an optional argument and a compulsory argument.
	
	The default number of dots is 1, but it may be any whole number bigger than one. The second, compulsory argument is the height of the dot: \verb|\Dot[2]{7}|.
	
	\begin{center}
		\begin{mousik}		
			\Clef{2}
			
			\TTT{Dot\{5\}}
			\TTT[-0.5]{Note\{4\}\{5\}}
			\Dot{5}
			\Note{4}{5}
			
			\Space[3]
			
			\TTT{Dot[2]\{7\}}
			\TTT[-0.5]{Rest\{8\}}
			\Dot[2]{7}
			\Rest{8}
			
			\Bar[|.]
		\end{mousik}
	\end{center}

	\subsection{\texttt{\textbackslash Text} and \texttt{\textbackslash Dynamics}}
	The \verb|\Text| command allows the printing of any text string. It has a compulsory argument, but also an optional one where the user may choose the height of the string: \verb|\Text[2]{\it rit.}|.
	
	To write anything in the usual font of dynamics, the \verb|\Dynamics| command will work the same: \verb|\Dynamics[-0.5]{pp}|.
	\begin{center}
		\begin{mousik}
			\Clef{2}
			\Key{-3}
			\TimeSig{2}{4}
			
			\Text{C}
			\Note{4}{0}
			
			\Note{8}{1,2}		
			\Chord
			\Text{E}
			\Space
			
			\Bar
			
			\Text[2]{\it rit.}
			\Note{8}{3,4}
			
			\Dynamics[-0.5]{pp}
			\Note{4}{-3}
			
			\Bar[|.]
		\end{mousik}
	\end{center}
